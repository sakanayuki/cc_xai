# XI clone — DICE PUZZLE

PlayStation の名作パズル **XI [sái]（Devil Dice）** にインスパイアされたブラウザゲームです。
ビルド不要の純粋な静的サイト（HTML / CSS / Vanilla JavaScript）なので、GitHub Pages でそのまま公開できます。

## 遊び方

- **↑↓←→ / WASD** … 移動
- **R** … リスタート
- スマホではタッチ用の十字キーが表示されます

### ルール

1. サイコロの **上に乗って歩く** と、その方向にサイコロが転がる
2. 地上からサイコロに向かって歩くと、**出目を保ったまま横に滑らせて押せる**（後ろが塞がっていると押せない）
3. サイコロの上に乗るには、**黄色い点滅枠の上に立って待つ** — 湧き上がるサイコロに持ち上げてもらえる
4. 上面が同じ目のサイコロが **「目の数」以上** 隣接すると、点滅しながら **徐々に地面へ沈んで** 消える
   （例: 5 の目なら 5 個以上）
5. 沈みかけのサイコロも、**高さが半分以上残っていれば** 飛び移れる
6. 沈んでいる間に同じ目のサイコロを隣接させると **連鎖(CHAIN)** — グループがせり上がって延命し、得点倍率が上がる
7. **1 の目は単独では消えない**。沈んでいるサイコロに隣接させると、**盤上の 1 がすべてまとめて消える**
8. サイコロは黄色い点滅枠の場所に湧く。湧くペースはプレイ時間とともに速くなり、**盤面が埋まったらゲームオーバー**

## ローカルで遊ぶ

`index.html` をブラウザで開くだけです。ローカルサーバを使う場合:

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

## GitHub Pages で公開する

このリポジトリには GitHub Actions のデプロイワークフロー（`.github/workflows/deploy.yml`）が含まれています。

1. リポジトリの **Settings → Pages** を開く
2. **Source** を **GitHub Actions** に設定する
3. `main` ブランチに push すると自動でデプロイされる
   （`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開）

ワークフローを使わない場合は、**Settings → Pages → Source: Deploy from a branch** で
ブランチと `/ (root)` を選ぶだけでも公開できます（ビルド工程が無いため、どちらでも動きます）。

## 技術構成

- 依存ライブラリ・ビルドツールなし（HTML + CSS + Vanilla JS の 3 ファイル）
- サイコロは **CSS 3D Transform** で実体のある立方体として描画し、辺を軸に 90° 回転させて転がりを表現
- サイコロの向きは（上面・北面・東面）の 3 値で管理し、右手系の標準ダイスから到達可能な 24 姿勢を列挙して整合性を保証
- ハイスコアは `localStorage` に保存
